# IGC Explorer

Simulador interactivo del **Impuesto Global Complementario** (Chile, Art. 52 LIR · AT 2026).

Ajusta sueldo, bono, alza y ganancia de fondos; el impuesto se muestra como el área bajo la escalera de tasas marginales.

## Desarrollo local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## GitHub Pages

El sitio se publica en:

**https://cubellij.github.io/igc-explorer/**

Cada push a `main` dispara el workflow en `.github/workflows/deploy.yml`.

En el repo: **Settings → Pages → Source: GitHub Actions**.
